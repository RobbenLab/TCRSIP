#A file describing the input text definition
#
# Channel definitions for the 2D TCR-pMHC input maps built by src/build_inputs.py.
# This file is documentation only - no script reads it. The definitions it describes live
# in src/build_inputs.py: CHANNELS (channel list and order) and TRIM (the @ trimming
# settings), and in src/tcr_dataset.py: CANVAS (the @ canvas settings). Keep them in sync
# when changing either side.
#
# Every channel is an L x L map over residue pairs (i, j), where residues are ordered
# MHCa, MHCb, Peptide, TCRa, TCRb (chain IDs A, B, C, D, E) to match the JSON sequences.
# Each complex is first trimmed (rules below); maps are stored unpadded (L = trimmed length,
# ~410) as float16 in physical units. Centering, padding and per-channel normalization
# happen at load time (src/tcr_dataset.py).
# Symmetry: sym = M[i,j] == M[j,i], anti = M[i,j] == -M[j,i], asym = directional.
#
# Lines starting with @ are settings: @name value [value ...] (= TRIM / CANVAS entries)
# Channel lines: index  name  group  symmetry  description
# Groups (used for hold-out experiments): sequence, position, structure, physics

######## Trimming rules ########
# Goal: keep the parts of the complex that form the interface (MHC peptide-binding platform
# and the full TCR variable domains with all CDRs), and trim every structure to the same
# domain boundaries so chain length does not encode the data source. Without trimming, Test
# structures carry signal peptides (24 residues on MHCa, ~20 on each TCR chain), full MHC
# alpha3/TM and TCR constant domains while PDB structures do not, so padding alone would
# reveal the source. The JSON Region offsets are not used for trimming: they ignore the
# signal peptides and many CDR3 ranges are wrong.
#
# MHC class I (MHCa): keep the alpha1 + alpha2 domains (both helices and the beta-sheet
#   floor), drop alpha3 / transmembrane / cytoplasmic (and any signal peptide).
#   Start anchor: motif H[ST][LM]RY (HLA ...GSHSMRY, H = residue 3) -> chain start = H - 2,
#   i.e. HLA residue 1. Missing motif -> start at residue 0 and flag no_mhc1_motif.
#   End: keep @mhc1_keep residues from the start (HLA 1-180; alpha3 begins at ~182).
@mhc1_keep          180
#   Helix regions for the pos_region channels, as [start, end) offsets from HLA residue 1:
@mhc1_helix_a       49 83
@mhc1_helix_b       138 175
#
# MHC class II (MHCa alpha1, MHCb beta1): the dataset already contains only the
#   peptide-binding domains (78-95 residues, no signal peptides), so both chains are kept
#   whole and the JSON Region helix offsets (MHCha on MHCa, MHChb on MHCb) are used.
#   Chains longer than @mhc2_max_len are flagged mhc2_long (alpha2/beta2 domain present?).
@mhc2_max_len       100
#
# Peptide: kept whole. Complexes with no peptide or no MHC class (CD1/MR1-type complexes
#   presenting lipids/metabolites) are skipped.
#
# TCR alpha/beta: keep the variable domain (IMGT 1-128) including CDR1, CDR2, CDR3 and the
#   J region; drop the signal peptide and the constant domain.
#   Start anchor: first Cys followed 10-18 residues later by W[YF] (conserved Cys23 and
#   Trp41) -> start = Cys23 - @tcr_pre_cys (clipped at 0). Missing -> start 0, flag no_cys23.
@tcr_pre_cys        22
#   End anchor: last J-region motif [FW]G.G (Phe118-Gly119-X-Gly121) within the first 170
#   residues -> end = F118 + @tcr_post_j (IMGT 128, end of the V domain). Missing -> end =
#   start + @tcr_fallback_len, flag no_J.
@tcr_post_j         10
@tcr_fallback_len   120
#   Chains shorter than @tcr_min_len after trimming are flagged short_tcr (fragments).
@tcr_min_len        60
#   CDRs for the pos_region channels come from the JSON per-residue IMGT numbering
#   (Sequence.<chain>.Consensus.IMGT: CDR1 = 27-38, CDR2 = 56-65, CDR3 = 105-117). Where it
#   is missing, they come from the anchors (flag cdr_from_anchors): CDR1 = Cys23+4 to
#   Trp41-3, CDR2 = Trp41+15 to Trp41+25, CDR3 = after the last Cys before F118 up to F118.

######## Canvas (load-time centering and padding) ########
# Each trimmed map is placed on a @canvas_size x @canvas_size canvas so that the last
# peptide residue sits at index @anchor on both axes: the pMHC side (MHCa, MHCb, peptide)
# fills rows/cols up to the anchor and the TCR side starts at anchor + 1, so the pMHC-TCR
# interface block is always in the same place. With the rules above the full dataset has
# pMHC side <= 204 and TCR side <= 247 residues, so 512 with the anchor at 255 (TCR starts
# at the canvas center) fits everything. Padding uses @pad_value (as in the notebook).
@canvas_size        512
@anchor             255
@pad_value          -1
